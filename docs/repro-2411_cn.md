### 2.4 `label{站号}.npy` 弃用依据

57687 / 58238 两站实测：按 `label[t] ↔ data[t+1]` 对齐后，
`label[:, :, 1]` 与 `-data[:, 1:, 4]`（10V）高度接近，MAE 分别为
0.000653 / 0.001581，相关系数分别为 0.99999993 / 0.99999921；
并非逐位相等。`label[:, :, 0]` 与 10U 不符。结论：label 是模式派生量，
不是观测，用它训练等于模式拟合模式。

## 3. 观测清洗规则（7 步，按顺序执行）

```text
1) 特殊码分类（先于一切数值判断）
   dir_calm = (dir == 999017)                 # 静风，风向无意义
   dir_miss = (dir >= 999990) & ~dir_calm     # 999999 / 999990 → 缺测
   spd_miss = (spd >= 999990)
   pre_miss = (pre >= 999990)

2) 物理范围
   dir = where(dir == 360, 0, dir)
   dir[(dir < 0) | (dir > 360)] = NaN
   spd[(spd < 0) | (spd >= 1000)] = NaN

3) 成对一致
   dir[spd_miss] = NaN ; spd[spd_miss] = NaN
   dir[dir_miss] = NaN

4) 静风
   calm = dir_calm & (spd < 0.3)
   dir[calm] = 999017 ; spd[calm] 保留原值

5) 时间一致性
   |spd[t] - spd[t-1]| > 10 m/s → dir[t], spd[t] 置 NaN

6) 降水
   pre[pre_miss] = NaN
   pre_mm_h = pre * 1000 / dt            # dt = 3 (t<=23) / 6 (t>=24)

7) 2024 重叠段去重
   concat(根目录, 2024子目录).drop_duplicates(subset=['Datetime'])
```

**验收**：日志逐站输出 静风率 / 缺测率 / 突变剔除率 / 降水异常率；任一比率 > 30% 的站列入报告。
